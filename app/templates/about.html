ABOUT THE PROJECT

Practical ML. Clearer decisions.

LapPrice AI is a machine-learning project that estimates laptop prices from hardware specifications, with an emphasis on usable predictions and model transparency.

01

Input specifications

Brand, CPU configuration, RAM, storage, display details, GPU, operating system and warranty are assembled into a single model input.

02

Engineer features

The application derives display megapixels, pixel density and whether a dedicated GPU is present before making a prediction.

03

Predict price

The saved scikit-learn pipeline processes the specification row and returns an estimated price in Indian rupees.

Important to know

This is an educational decision-support tool, not a guarantee of resale value or current market price. Results depend on the training dataset, its coverage and the input values. Verify current listings before making a purchase.

Technology: Python, Flask, pandas, NumPy, joblib and scikit-learn.
